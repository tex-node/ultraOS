# Accessibility Standards

## Writing

- Use plain language.
- Define product terms on first use.
- Avoid instructions that depend only on color or screen position.

## Images

- Every image needs alt text.
- Screenshots must have descriptive captions.
- Do not rely on images as the only source of procedural information.

## Tables

- Use clear headers.
- Keep tables narrow enough for PDF export where possible.

## Links

- Link text must describe the destination.
- Avoid `click here`.
