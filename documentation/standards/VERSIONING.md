# Documentation Versioning

Documentation versioning is separate from software versioning.

## Version Format

Use:

```text
docs-MAJOR.MINOR
```

Examples:

- `docs-0.1`
- `docs-1.0`
- `docs-1.1`

## Status Values

- Draft: Work in progress.
- Internal: Usable internally.
- Review: Awaiting review.
- Approved: Reviewed and accepted.
- Published: Released to the intended audience.
- Archived: Superseded but retained.

## Change Tracking

- Update `CHANGELOG.md` for approved or published changes.
- Use revision-history tables on long-lived pages.
- For operational procedures, include the effective date.
- Never silently replace safety-critical instructions.
