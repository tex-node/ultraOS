# Terminology Standards

All documents must use terms from the canonical [Glossary](../reference/GLOSSARY.md).

## Rules

- Use `Athlete` for the permanent person profile.
- Use `Player` for an Athlete registered for a Season.
- Use `Club` for permanent brand identity.
- Use `SeasonClub` for a Club participating in a specific Season, Division, or Competition.
- Use `Fixture` for the scheduled match.
- Use `Game` for the live or played instance.
- Use `DraftEvent` for the operational draft event.
- Use `Ultra Athlete ID` and `Ultra Staff ID` for public participant identifiers.

## Disallowed Ambiguity

- Do not use `team` when the system object is specifically `SeasonClub`.
- Do not use `player` when the record is an `Athlete` profile.
- Do not use `match` when the system object is specifically `Fixture` or `Game`.
