# Screenshot Guide

## Resolution

- Default capture width: `1440px`.
- Use full-page screenshots only when layout context is important.
- Crop to the relevant UI area for procedures.

## Theme and Browser

- Use the production visual theme unless documenting an internal-only screen.
- Preferred browser: Chrome.
- Hide browser bookmarks and personal extensions.

## Naming

Use:

```text
yyyy-mm-dd-area-screen-purpose.png
```

Example:

```text
2026-08-02-draft-readiness-dashboard-overview.png
```

## Annotation Style

- Use numbered callouts.
- Keep arrows and boxes high contrast.
- Do not obscure primary UI labels.

## Redaction Rules

Redact:

- Passwords
- Tokens
- Emails
- Phone numbers
- Emergency contacts
- Private application details
- Payment details

## Placeholder Syntax

Use this syntax until screenshots are captured:

```text
[Screenshot Placeholder:
Draft Readiness Dashboard]
```
