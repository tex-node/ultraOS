# Season Zero Manual Player Stat Sheets

One reusable template per club — photocopy for each game that club plays. Columns follow the current `PlayerStat` schema exactly (points, rebounds, assists, steals, blocks, turnovers, fouls) plus the requested shot-type breakdown, which is flagged below since the system does not store it as separate fields.

**MANUAL ONLY — 1PT / 2PT / 3PT / 4PT columns:** the digital scorer stores only a single running `points` total per player per game (from the Ultra Rules Engine's base-value × multiplier event log). It does not persist a separate tally by shot type. Use these columns for the paper record and cross-check the sum against the digital total; do not expect them to sync back into the system.
