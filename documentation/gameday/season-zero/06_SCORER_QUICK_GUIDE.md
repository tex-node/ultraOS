# Season Zero Scorer Quick Guide

*Target: ~2 printed pages. Laminate for courtside use.*

## ⚠ NEVER GUESS A SCORE. NEVER FINALIZE AN UNVERIFIED SCORE. ⚠

## PRE-GAME

- [ ] Open the correct fixture on the running order (check fixture number AND team names).
- [ ] Verify both clubs match the running order.
- [ ] Verify rosters against the Club Roster / Check-In Pack.
- [ ] Verify jersey numbers are visible/recorded (see Jersey Number Capture Sheet).
- [ ] Verify score reads 0–0.
- [ ] Verify game clock is reset (10:00 per half).
- [ ] Verify shot clock is reset (20 seconds).
- [ ] Confirm every operator (Assistant Scorer, Shot-Clock Operator, Event Director) is ready.

## DURING GAME

- **Start / Stop** the game clock from the scorer console.
- **Reset** the shot clock after a change of possession, coordinated with the Shot-Clock Operator.
- **+1 / +2 / +3 / +4** — one tap selects the value and submits in the same action. Confirm the player/jersey before tapping.
- **Ultra Time** — in the final 60 seconds of Half 2, all scored points are automatically doubled by the system. No manual action needed; just confirm the console shows the Ultra Time indicator.
- **Mandatory second-half substitution confirmation** — before Half 2 starts, confirm the substitution with the Assistant Scorer out loud.
- **Undo / correction** — use the Undo control immediately after a mis-entry. For anything beyond the single most recent event, use the manual correction section and state the reason out loud.
- **Incident** — use the Incident panel on the scorer console for any delay, player unavailability, clock correction, or interruption. Announce it verbally as it happens (see [Emergency Procedures](12_EMERGENCY_PROCEDURES.md)).

## END GAME

- [ ] Stop the clock.
- [ ] Verbally verify the final score with the Assistant Scorer.
- [ ] Compare venue display, broadcast graphics, and the manual score sheet — all three must agree.
- [ ] Only Finalize once verification is complete.
