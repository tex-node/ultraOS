# Season Zero Jersey Number Capture Sheet

## JERSEY NUMBER CAPTURE REQUIRED BEFORE FIRST GAME

As of 2026-08-13, **0 of 67** rostered players have a jersey number recorded in production. This sheet is the collection tool — it does not write anything to the system by itself.

## Recommended Workflow

1. Capture jersey number during check-in.
2. A second person visually verifies the jersey against the number written down.
3. Scorer/Admin enters the number into the roster record.
4. Verify the number now shows correctly on the scorer console.
5. Mark **Entered Into System** on this sheet.

No duplicate jersey numbers within the same club (duplicates across different clubs are fine).
