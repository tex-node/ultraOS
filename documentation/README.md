# UltraLeagueOS Documentation

This directory is the official documentation foundation for the Ultra Sports League Operating System.

It is designed to publish cleanly to GitHub, MkDocs, Docusaurus, GitBook, PDF, and DOCX. Keep documents in portable Markdown unless a publishing target requires a generated artifact.

## Publishing Principles

- Source of truth is Markdown.
- Diagrams use Mermaid source files or fenced Mermaid blocks.
- Screenshots must follow redaction and naming rules before publication.
- Terms must match the canonical glossary.
- Software versioning and documentation versioning are tracked separately.
