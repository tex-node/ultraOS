# Season Zero Scorer Quick Guide

*Print double-sided. This is the only sheet you should need at the table.*

## BEFORE GAME

1. Open `https://app.neonultra.ng/games/[fixtureId]/live` for the correct
   fixture — Assistant Scorer reads the Fixture ID aloud, you confirm it
   matches the screen.
2. Confirm Home Club and Away Club on screen match the two teams on the
   court.
3. Confirm shot clock shows 20.
4. Wait for the Event Director's spoken "Scorer ready" cue.

## START GAME

Tap **Start game**. Confirm the clock begins counting down from 10:00 and
status shows LIVE.

## SCORING

Pick the scoring player from the dropdown (or leave "Team score / unknown
player" if you didn't see who scored), then tap the exact shot:

**+1 · +2 · +3 · +4**

During Ultra Time the button shows the doubled value under the shot value —
**tap what you actually saw, not the doubled number.** The server doubles it
for you.

## SHOT CLOCK

**Start** / **Stop** / **Reset 20** — coordinate with the Shot-Clock Operator
if that's a separate station.

## UNDO LAST EVENT

Made a mistake on the very last thing you entered? Tap **Undo last event**.
It only ever undoes the single most recent action — if you need to fix
something further back, use the manual correction fields instead (open
"Manual correction" under the scoring buttons).

## HALFTIME

Tap **Next period**. Clock resets to 10:00, score carries over, nothing else
changes automatically.

## SECOND-HALF SUBSTITUTION

At the start of Half 2 a **Mandatory second-half substitution check** panel
appears for both clubs. Tap **Confirm** for each club once you've verified
the required substitution happened — spoken confirmation from the Floor
Runner is enough, you don't need to see it yourself.

## ULTRA TIME

Automatic. When the clock hits 1:00 in Half 2, a
**⚡ ULTRA TIME — 2× POINTS** banner appears. Score normally — see SCORING
above.

## INCIDENT

If something needs recording (delay, interruption, clock correction, player
unavailable), scroll to **Incidents**, pick the type, write a one-line
reason, submit. For a clock correction specifically, enter the correct
minutes/seconds — the game must be Paused first.

## FINALIZE

Only after: Head Scorer reads the score aloud, Assistant Scorer verifies it,
Event Director confirms no open dispute. Then tap **Confirm final**. The
game locks — normal scoring controls disable.

## REOPEN

Only the Event Director authorizes this. Whoever has `result:confirm` access
enters a written reason and taps **Reopen finalized game**. The game returns
to Paused for correction, then must be finalized again.

## WHAT NEVER TO DO

- **Never** ask anyone to edit the database directly, for any reason, under
  any pressure. Every correction has an audited button for it.
- **Never** run two scorers on the same console at the same time unless one
  is explicitly taking over from the other.
- **Never** finalize before the score has been read aloud and verified.
- **Never** guess a score if the digital and paper records disagree — pause
  and escalate to the Event Director.
