# Season Zero Manual Player Stats Sheet

## Purpose

Paper fallback for per-player stats, alongside the digital scorer's stat
entry (rebound/assist/steal/block/turnover/foul). Print one per club per game.

## Print one per club per game

```
ULTRA BASKETBALL — SEASON ZERO — MANUAL PLAYER STATS

Game ID / Fixture: ______________________
Club: ___________________         Operator: ___________________

Player                    UBA ID          #    PTS  REB  AST  STL  BLK  TOV  FOUL

Verified against digital record by: ___________________  Time: __________
```

## Notes

Jersey numbers are not currently populated in production for any player
(see [Roster Pack](../gameday/season-zero/10_ROSTER_PACK.md) notes) — leave
the `#` column blank if unassigned rather than guessing one.
