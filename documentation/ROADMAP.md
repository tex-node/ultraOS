## Estimated Completion Stages

- Draft: outline exists and is actively changing.
- Internal: usable internally but not yet reviewed.
- Review: ready for subject-matter review.
- Approved: accepted as correct for current operations.
- Published: released to users or operators.
- Archived: retained for historical reference.

## Near-Term Documentation Work

- Populate the Administrator Guide with account, role, application review, and audit workflows.
- Populate the Operations Handbook with draft day, fixture, live scoring, and event runbooks.
- Add architecture diagrams for authentication, participant internalization, and matchday operations.
- Add screenshots after UI flows stabilize.
- Add API reference pages once public and operational APIs are finalized.
