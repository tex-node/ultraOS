# Contributing to Documentation

## Scope

Documentation changes must be made under `documentation/` unless a task explicitly updates product docs elsewhere.

## Workflow

1. Select the correct section and template.
2. Confirm terminology against [Glossary](reference/GLOSSARY.md).
3. Write in portable Markdown.
4. Add front matter.
5. Add related links.
6. Update [INDEX.md](INDEX.md) or the nearest section README when adding major pages.
7. Update [CHANGELOG.md](CHANGELOG.md) for published documentation changes.

## Review Checklist

- Headings use sentence-style names unless a product term requires title case.
- Code blocks include language identifiers.
- Screenshots are redacted.
- Warnings are specific and actionable.
- Procedures include prerequisites and expected results.
- Version and status are current.
