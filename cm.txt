feat(deploy): keep the whole transcript and propagate the deploy's exit code

Prompt 1 (streak v23). The v22 "silent deploy" was not the deploy script - it runs under set -euo pipefail and exits
non-zero (demonstrated: a bogus flag exits 2 while the piped form reports grep's 1). It was the pipeline I wrapped around
it: `ssh host "bash deploy.sh | grep ... | tail"` returns GREP's status, and a deploy that fails before printing a
matching line is indistinguishable from one that printed nothing.

deploy/ops/deploy-with-log.sh runs the deploy with no pipe, writes the full transcript to deploy-logs/, prints the last
few lines, and exits with the deploy's own status. Two unfiltered production deploys are committed as evidence, one of
them run with `bash -x`.
